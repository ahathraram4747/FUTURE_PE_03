# SEO Content Prompt System

## Master Prompt

Act as an experienced SEO content strategist and business blog writer.

Create a complete SEO content plan for a business website.

Before writing, identify:
- Primary keyword
- Secondary keywords
- Search intent
- Target audience
- Main user problem
- Business/service context

Create one main pillar blog and 4 supporting blog topics around the same subject.

For the pillar blog:
- Create an SEO-friendly title
- Write a clear H1
- Organize the article using H2 and H3 headings
- Provide a useful introduction
- Answer the user's search intent
- Use keywords naturally
- Keep the writing helpful, clear, and easy to read
- Include relevant internal linking opportunities
- End with a useful conclusion and CTA

For supporting blogs:
- Give each article a unique SEO title
- Define its search intent
- Suggest primary and secondary keywords
- Explain how it supports the pillar article
- Suggest an internal link to or from the pillar article

For local SEO:
- Include the target city/location where relevant
- Combine location and service keywords naturally
- Avoid keyword stuffing

The final content should be helpful, human-readable, business-focused, and suitable for search engines without sounding robotic.

## Output Structure

1. Keyword Strategy
2. Search Intent
3. Pillar Blog Topic
4. Pillar Blog Outline
5. Four Supporting Blog Topics
6. Internal Linking Plan
7. Local SEO Opportunities
8. Content Writing Guidelines
